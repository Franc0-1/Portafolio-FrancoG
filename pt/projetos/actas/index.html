02Automação administrativa

Gerador de Atas

Documentos administrativos, gerados pela web.

Estágio · Casa de Governo da Província do Chaco

Desafio
Cada ata exige preencher dados, validá-los e produzir o documento no formato certo.
Resultado
Um formulário web gera a ata em DOCX e PDF, com nome de arquivo automático.

Sobre o projeto

Sistema em Go que gera atas administrativas dinâmicas em DOCX e automatiza a conversão para PDF com o LibreOffice em modo headless.

Problema
Preparar atas administrativas exige preencher informações, validar os dados e produzir documentos nos formatos necessários.
Solução
Uma interface web conectada a uma API HTTP gera os documentos, nomeia os arquivos automaticamente e os converte de DOCX para PDF.

Abordagem técnica

  • API HTTP em Go e interface web para inserir os dados e gerar as atas.
  • LibreOffice em modo headless para automatizar a conversão de DOCX para PDF.
  • Docker e Docker Compose para executar o serviço implantado no Proxmox.
