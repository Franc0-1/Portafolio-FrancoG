03Frontend / Demo visual

Horizonte Global

Landing page e CRM para uma agência de viagens.

Projeto freelance

Desafio
Apresentar a agência e organizar clientes e trâmites migratórios em uma única interface.
Resultado
Landing page multilíngue e CRM navegável em React, como demo visual com dados simulados.

Sobre o projeto

Protótipo frontend para uma agência de viagens e mobilidade internacional. Inclui uma landing page multilíngue e um CRM com clientes, casos, documentos, calendário e equipe, usando dados simulados.

Problema
Apresentar a agência e explorar visualmente como organizar clientes e processos migratórios em uma única interface.
Solução
Uma landing page e um painel navegáveis em React. O escopo é uma demo visual: sem backend, banco de dados nem integração com uma API real.

Abordagem técnica

  • Componentes para a landing page e o painel, com navegação via React Router.
  • Tailwind CSS, Framer Motion e Lucide para estilos, transições e ícones.
  • Dados simulados dentro do próprio frontend. O repositório não tem backend nem banco de dados.
