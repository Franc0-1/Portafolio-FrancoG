06Visão computacional

Classificador de imagens

API de classificação com uma ResNet50 pré-treinada. O Streamlit permite enviar imagens e o Redis coordena o processamento das previsões.

Abordagem técnica

  • A interface, a API e o worker de inferência rodam como serviços separados com Docker Compose.
  • O worker pega tarefas de uma fila no Redis e salva a classe prevista e sua pontuação com o ID da tarefa.
  • As imagens são redimensionadas para 224 × 224 pixels e pré-processadas para a ResNet50. É retornada a classe do ImageNet com a maior pontuação.
  • O escopo é integrar um modelo pré-treinado com uma API e uma interface de envio; as categorias disponíveis são as do ImageNet.
Stack
  • Python
  • FastAPI
  • Streamlit
  • TensorFlow / Keras
  • Redis
  • Docker Compose
