Sistema de Inventário

Do Excel ao SQL Server, com gestão web do inventário.

Estágio · Casa de Governo da Província do Chaco

Desafio
O inventário era buscado e gerenciado à mão em planilhas do Excel.
Resultado
Gestão web com SQL Server: busca, filtros, empréstimos e histórico de movimentações.

Sobre o projeto

Aplicação interna em Go para gerenciar equipamentos, estoque de insumos, empréstimos e histórico de movimentações a partir de uma interface web, com resumo e relatórios.

Problema
A busca e a gestão manual do inventário no Excel dificultavam o acesso às informações e o controle dos dispositivos.
Solução
Uma API REST em Go com interface web: CRUD, busca, filtros, ordenação e paginação. Os dados ficam no SQL Server; o Excel fica para importar e exportar.

Abordagem técnica

  • Camadas separadas: handlers HTTP, serviços com a lógica de negócio e repositórios intercambiáveis (SQL Server ou Excel) atrás da mesma interface.
  • Migrações SQL e ferramentas de linha de comando para preparar o banco e migrar os dados das planilhas.
  • Movimentações de estoque (entrada, saída, ajuste e transferência), empréstimos que vencem no fim do expediente, resumo e relatórios.
  • Docker Compose com um contêiner reforçado: sistema de arquivos somente leitura, sem privilégios extras e logs rotacionados.
  • Testes em Go para handlers, serviços e repositórios, além de testes do frontend.
