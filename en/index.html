More details

Internal Go application to manage equipment, supply stock, loans and movement history from a web interface, with a summary and reports.

Problem
Searching and managing the inventory by hand in Excel made it hard to access the information and manage the devices.
Solution
A Go REST API with a web interface: CRUD, search, filters, sorting and pagination. Data lives in SQL Server; Excel remains for import and export.
  • Separate layers: HTTP handlers, services with the business logic and interchangeable repositories (SQL Server or Excel) behind the same interface.
  • SQL migrations and command-line tools to set up the database and migrate the data from the spreadsheets.
  • Stock movements (in, out, adjustment and transfer), loans that expire at the end of the workday, summary and reports.
  • Docker Compose with a hardened container: read-only file system, no extra privileges and rotated logs.
  • Go tests for handlers, services and repositories, plus frontend tests.

04Computer vision

Image Classifier

Classification API with a pretrained ResNet50. Streamlit lets users upload images and Redis coordinates the prediction processing.

  • Python
  • FastAPI
  • Streamlit
  • TensorFlow / Keras
  • Redis
  • Docker Compose
View repository ↗
Technical approach
  • The interface, the API and the inference worker run as separate services with Docker Compose.
  • The worker takes jobs from a Redis queue and stores the predicted class and its score under the job ID.
  • Images are resized to 224 × 224 pixels and preprocessed for ResNet50. The top-scoring ImageNet class is returned.
  • The scope is integrating a pretrained model with an API and an upload interface; the available categories are those of ImageNet.

05Predictive models

Home Credit: credit risk

Analysis of 307,511 loan applications and comparison of logistic regression, Random Forest and LightGBM to estimate the risk of payment difficulties.

0.7551ROC AUC · ValidationLightGBM · 49,202 applications in validation.

  • Logistic Regression
  • Random Forest
  • LightGBM
View repository ↗View evaluation ↗
Technical approach
  • Dataset: 246,008 applications for training and 61,503 for test. 20% of the training set is held out for validation: 196,806 to train and 49,202 to evaluate, with seed 42.
  • Validation ROC AUC: 0.6772 with the initial logistic regression, 0.7465 inside a pipeline, 0.7323 with a tuned Random Forest and 0.7551 with LightGBM.
  • LightGBM uses early stopping and reaches its best iteration at round 218. The result corresponds to the validation set used during tuning, not to the test set.
  • Metrics come from the outputs saved in the notebook; the experiment was not rerun for this portfolio.
