About the project

Frontend prototype for a travel and international mobility agency. It includes a multilingual landing page and a CRM with clients, cases, documents, calendar and team, using mock data.

Problem
Presenting the agency and visually exploring how to organize clients and immigration processes in a single interface.
Solution
A navigable landing page and dashboard in React. The scope is a visual demo: no backend, database or real API integration.

Technical approach

  • Components for the landing page and dashboard, with navigation through React Router.
  • Tailwind CSS, Framer Motion and Lucide for styles, transitions and icons.
  • Mock data inside the frontend itself. The repository has no backend or database.
