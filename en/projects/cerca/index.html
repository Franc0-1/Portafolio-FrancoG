Personal project

Challenge
Keeping up with savings when progress is invisible and every month you have to decide how much to set aside.
Result
Every contribution moves the goal along a path with an estimated arrival date and a calculated monthly plan.

About the project

Goal-based savings app with its own visual identity. Each goal is a postcard with its photo and a path that shows progress, the estimated arrival date and the monthly plan based on salary, fixed expenses and freelance work.

Problem
Saving for something specific gets abandoned when progress is invisible and it is unclear how much to set aside each month.
Solution
An app that turns every contribution into visible progress: percentage, pace, estimated date and a monthly plan that splits salary and freelance income across goals.

Technical approach

  • Pure, tested domain logic: percentage, pace and estimated date, monthly plan, freelance split and payday (monthly or twice a month).
  • Data layer behind an interface: IndexedDB with idb today; moving to a backend means swapping the implementation without touching the screens.
  • Installable and offline, with a JSON backup (photos included) to move data between devices.
  • Its own design system with light and dark themes defined as tokens and exposed to Tailwind CSS.
  • Vitest tests for the logic and fake-indexeddb for the data layer.

Scope
