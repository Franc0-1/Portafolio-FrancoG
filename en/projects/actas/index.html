Result

About the project

Go system that generates dynamic administrative records as DOCX and automates their conversion to PDF with headless LibreOffice.

Problem
Preparing administrative records requires filling in information, validating the data and producing documents in the required formats.
Solution
A web interface connected to an HTTP API generates the documents, names the files automatically and converts them from DOCX to PDF.

Technical approach

  • Go HTTP API and web interface to enter data and generate records.
  • LibreOffice in headless mode to automate the DOCX to PDF conversion.
  • Docker and Docker Compose to run the service deployed on Proxmox.
