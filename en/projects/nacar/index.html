Challenge
Show treatments, durations and prices without answering every inquiry by hand.
Result
A catalog with search and filters that leads to each treatment and opens WhatsApp with the booking already requested.

About the project

Website for a beauty centre built to be adapted to each client: name, contact details, treatments, prices and copy live in configuration files. It uses a fictional brand and sample data.

Problem
Many beauty centres get inquiries over WhatsApp with no place to show their treatments, durations and prices.
Solution
A landing page that presents the centre and a catalog where each treatment shows its duration and an indicative price, with a button that opens WhatsApp with the booking request already written.

Technical approach

  • Catalog of 16 treatments in 6 categories, with search, duration filter and sorting; filters live in the URL, so a link shares the same view.
  • A page per treatment with duration, indicative price and variants, plus WhatsApp links with a ready-made message to book or ask a question.
  • Business details, treatments and copy kept in configuration files, so it can be adapted to a real client without touching the components.
  • Palette and typefaces defined as Tailwind CSS 4 tokens; routing with React Router and a SPA fallback for direct links.
