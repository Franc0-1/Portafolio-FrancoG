Más detalles

Aplicación interna en Go para administrar equipos, stock de insumos, préstamos e historial de movimientos desde una interfaz web, con resumen y reportes.

Problema
La búsqueda y administración manual del inventario en Excel dificultaba acceder a la información y gestionar los dispositivos.
Solución
Una API REST en Go con interfaz web: CRUD, búsqueda, filtros, orden y paginación. Los datos viven en SQL Server; Excel queda para importar y exportar.
  • Capas separadas: handlers HTTP, servicios con la lógica de negocio y repositorios intercambiables (SQL Server o Excel) detrás de una misma interfaz.
  • Migraciones SQL y herramientas de línea de comandos para preparar la base y migrar los datos desde las planillas.
  • Movimientos de stock (entrada, salida, ajuste y transferencia), préstamos con vencimiento al cierre de la jornada, resumen y reportes.
  • Docker Compose con un contenedor endurecido: sistema de archivos de solo lectura, sin privilegios adicionales y logs rotados.
  • Tests en Go para handlers, servicios y repositorios, y tests del frontend.

Sistema en Go que genera actas dinámicas en DOCX y automatiza su conversión a PDF con LibreOffice headless.

La preparación de actas administrativas requiere completar información, validar los datos y producir documentos en los formatos necesarios.

  • Docker y Docker Compose para ejecutar el servicio desplegado en Proxmox.

04Visión por computadora

Clasificador de imágenes

API de clasificación con ResNet50 preentrenada. Streamlit permite cargar imágenes y Redis coordina el procesamiento de las predicciones.

  • Python
  • FastAPI
  • Streamlit
  • TensorFlow / Keras
  • Redis
  • Docker Compose
Ver repositorio ↗
Enfoque técnico
  • Separación de la interfaz, la API y el worker de inferencia en servicios con Docker Compose.
  • El worker recibe trabajos desde una cola Redis y guarda la clase predicha y su puntuación con el identificador del trabajo.
  • Las imágenes se redimensionan a 224 × 224 píxeles y se preprocesan para ResNet50. Se devuelve la categoría con mayor puntuación entre las clases de ImageNet.
  • El alcance es integrar un modelo preentrenado con una API y una interfaz de carga; las categorías disponibles son las de ImageNet.

05Modelos predictivos

Home Credit: riesgo crediticio

Análisis de 307.511 solicitudes de crédito y comparación de regresión logística, Random Forest y LightGBM para estimar el riesgo de dificultades de pago.

0,7551ROC AUC · ValidaciónLightGBM · 49.202 solicitudes en validación.

  • Logistic Regression
  • Random Forest
  • LightGBM
Ver repositorio ↗Ver evaluación ↗
Enfoque técnico
  • Dataset: 246.008 solicitudes para entrenamiento y 61.503 para test. Del conjunto de entrenamiento se reserva un 20% para validación: 196.806 para entrenar y 49.202 para evaluar, con semilla 42.
  • ROC AUC en validación: 0,6772 con la regresión logística inicial, 0,7465 al integrarla en un pipeline, 0,7323 con Random Forest ajustado y 0,7551 con LightGBM.
  • LightGBM usa early stopping y alcanza su mejor iteración en la ronda 218. El resultado corresponde a la validación usada durante el ajuste, no al conjunto de test.
  • Métricas de las salidas guardadas en el notebook; el experimento no se volvió a ejecutar para este portfolio.
