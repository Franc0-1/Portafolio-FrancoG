05Visión por computadora

Clasificador de imágenes

API de clasificación con ResNet50 preentrenada. Streamlit permite cargar imágenes y Redis coordina el procesamiento de las predicciones.

Enfoque técnico

  • Separación de la interfaz, la API y el worker de inferencia en servicios con Docker Compose.
  • El worker recibe trabajos desde una cola Redis y guarda la clase predicha y su puntuación con el identificador del trabajo.
  • Las imágenes se redimensionan a 224 × 224 píxeles y se preprocesan para ResNet50. Se devuelve la categoría con mayor puntuación entre las clases de ImageNet.
  • El alcance es integrar un modelo preentrenado con una API y una interfaz de carga; las categorías disponibles son las de ImageNet.
Stack
  • Python
  • FastAPI
  • Streamlit
  • TensorFlow / Keras
  • Redis
  • Docker Compose
