Sistema de Inventario

Del Excel a SQL Server, con gestión web del inventario.

Pasantía · Casa de Gobierno de la Provincia del Chaco

Desafío
El inventario se buscaba y administraba a mano en planillas de Excel.
Resultado
Gestión web con SQL Server: búsqueda, filtros, préstamos e historial de movimientos.

Sobre el proyecto

Aplicación interna en Go para administrar equipos, stock de insumos, préstamos e historial de movimientos desde una interfaz web, con resumen y reportes.

Problema
La búsqueda y administración manual del inventario en Excel dificultaba acceder a la información y gestionar los dispositivos.
Solución
Una API REST en Go con interfaz web: CRUD, búsqueda, filtros, orden y paginación. Los datos viven en SQL Server; Excel queda para importar y exportar.

Enfoque técnico

  • Capas separadas: handlers HTTP, servicios con la lógica de negocio y repositorios intercambiables (SQL Server o Excel) detrás de una misma interfaz.
  • Migraciones SQL y herramientas de línea de comandos para preparar la base y migrar los datos desde las planillas.
  • Movimientos de stock (entrada, salida, ajuste y transferencia), préstamos con vencimiento al cierre de la jornada, resumen y reportes.
  • Docker Compose con un contenedor endurecido: sistema de archivos de solo lectura, sin privilegios adicionales y logs rotados.
  • Tests en Go para handlers, servicios y repositorios, y tests del frontend.
