02Automatización administrativa

Generador de Actas

Documentos administrativos, generados desde la web.

Pasantía · Casa de Gobierno de la Provincia del Chaco

Desafío
Cada acta requiere completar datos, validarlos y producir el documento en el formato correcto.
Resultado
Un formulario web genera el acta en DOCX y PDF, con nombre de archivo automático.

Sobre el proyecto

Sistema en Go que genera actas dinámicas en DOCX y automatiza su conversión a PDF con LibreOffice headless.

Problema
La preparación de actas administrativas requiere completar información, validar los datos y producir documentos en los formatos necesarios.
Solución
Una interfaz web conectada a una API HTTP genera los documentos, asigna nombres automáticos a los archivos y los convierte de DOCX a PDF.

Enfoque técnico

  • API HTTP en Go e interfaz web para la carga de datos y generación de actas.
  • LibreOffice en modo headless para automatizar la conversión de DOCX a PDF.
  • Docker y Docker Compose para ejecutar el servicio desplegado en Proxmox.
