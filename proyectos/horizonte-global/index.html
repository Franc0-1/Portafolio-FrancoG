04Frontend / Demo visual

Horizonte Global

Landing y CRM para una agencia de viajes.

Proyecto freelance

Desafío
Presentar la agencia y organizar clientes y trámites migratorios en una misma interfaz.
Resultado
Landing multilingüe y CRM navegable en React, como demo visual con datos simulados.

Sobre el proyecto

Prototipo frontend para una agencia de viajes y movilidad internacional. Incluye una landing multilingüe y un CRM con clientes, casos, documentos, calendario y equipo, usando datos simulados.

Problema
Presentar la propuesta de la agencia y explorar visualmente cómo organizar clientes y procesos migratorios en una misma interfaz.
Solución
Una landing y un dashboard navegables en React. El alcance es una demo visual: no incluye backend, base de datos ni integración real con APIs.

Enfoque técnico

  • Componentes para landing y dashboard, con navegación mediante React Router.
  • Tailwind CSS, Framer Motion y Lucide para estilos, transiciones e iconos.
  • Datos simulados en el propio frontend. El repositorio no contiene backend ni base de datos.
Estado
Demo frontend
Alcance
Landing multilingüe y CRM navegable en React con datos simulados; sin backend ni base de datos.
Stack
